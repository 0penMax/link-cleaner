# Link Cleaner

> [!NOTE]  
> This repository is an analytics-cleared for of [repo](https://github.com/corbindavenport/link-cleaner).


[Link Cleaner](https://0penmax.github.io/link-cleaner) is a web app that removes tracking code, search parameters, and other data from URL links. The cleaned links can be copied to the clipboard, viewed as a QR code, send to installed applications using the Web Share API, or shared directly to social media platforms. Link Cleaner can also receive links through the your device's share menu as an installed web application.

![Screenshots of Link Cleaner](screen.png)

Link Cleaner uses code from [Link Cleaner JS](https://github.com/corbindavenport/link-cleaner-js/), [Bootstrap](https://getbootstrap.com/), and [EasyQRCodeJS](https://github.com/ushelp/EasyQRCodeJS). The logo is ["Link 45deg" from Boostrap Icons](https://icons.getbootstrap.com/icons/link-45deg/).
